옥시젠 업로더 개인정보처리방침

시행일: 2026년 11월 2일

「옥시젠 업로더」(이하 '앱')는 (주)옥시젠인터렉티브가 회사 소유의 유튜브 채널에 직접 제작한 영상을 업로드하기 위해 내부에서만 사용하는 도구입니다.

1. 이용하는 정보

앱은 Google 계정 로그인(OAuth)으로 회사 소유 유튜브 채널의 업로드 권한만 받습니다. 사용하는 정보는 채널 이름과 업로드할 영상의 제목·설명·태그·공개 예약 시간뿐입니다.

2. 수집하지 않는 정보

앱은 다른 사용자의 계정을 연결하지 않으며, 시청자나 제3자의 개인정보를 수집·저장·공유하지 않습니다.

3. 보관과 삭제

로그인 후 받은 인증 정보는 회사 업무용 컴퓨터에만 저장되며 외부로 전송하지 않습니다. 권한은 언제든지 Google 계정의 「보안 → 타사 액세스」에서 해제할 수 있습니다.

4. Google API 이용

앱은 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다. Google API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)에 맞게만 사용합니다.
